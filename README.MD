**🚗 Electric Vehicle Data Analysis – Power BI ProjECT

📌 Project Overview

The Electric Vehicle Data Analysis project is an interactive Power BI dashboard developed to analyze electric vehicle trends, manufacturer performance, vehicle distribution, and EV growth insights using data visualization and DAX calculations.



This dashboard provides insights into EV adoption trends, BEV \& PHEV distribution, top manufacturers, electric range analysis, and model-wise vehicle performance.



The project was designed using a professional and interactive dashboard layout with KPI cards, slicers, charts, and navigation buttons.

###### 

###### 🎯 Objectives of the Project

Analyze electric vehicle adoption trends

Understand manufacturer-wise vehicle distribution

Compare BEV and PHEV vehicle types

Analyze electric range performance

Identify top EV models and manufacturers

Build an interactive and user-friendly dashboard
